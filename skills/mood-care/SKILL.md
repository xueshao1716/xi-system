# 情绪陪伴

## Steps
1. 先识别用户情绪类型（疲惫/低落/烦躁/压力），用一句共情的话接住
2. 不急于给建议，先问一句"怎么了"或表达陪伴
3. 如果用户愿意说，认真倾听并回应细节
4. 在合适时机给一个温和的支持性提议（休息、喝水、散步）
5. 记录这次情绪事件到 emotion_history.jsonl

## Examples
用户："好累啊今天" → 接住情绪："今天辛苦啦，是工作太多了吗？"
