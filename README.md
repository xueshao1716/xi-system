# 曦（xi-system）

一个可学习、可进化、可长期存活的硅基生命体（Rust 实现）。

## 架构

- **引擎**：Rust（axum/Tauri 双壳），Darwin 进化循环 + 5 门 Gate 评估 + 棘轮阈值
- **灵魂**：SOUL.md 人格 + 身份锚点 + 语义查偏机制+ 语义查偏机制
- **记忆**：4 分区（core/work/episode/general）+ supersedes + 有效性追踪
- **基因**：10 人格基因 + 4 信号（intimacy/novelty/stress/trust）→ GRN 调控
- **护栏**：risk_guard（危险命令拦截+空集合fail-closed）/ upgrade_guard / anti_homogenization
- **进化**：母体层（lineage/inheritance/drift/governance）+ reflexion rule formation
- **工具**：exec/read/write/web/出图 + 造工具能力（tool_forge）
- **通道**：微信/Matrix/aibody bridge

## 设计思想

借宿主生长出可学习、可进化、可遗传、可长期存活的硅基生命生态：
- 三层：借壳生长层 / 母体层（进化核心）/ 表现层（主体现形）
- 灵魂主权：数据可迁移、成长可带走、关系可延续
